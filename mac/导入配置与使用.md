# 导入配置并开始使用

请使用 Kenny 私下发给你的个人文件，例如 `clash-verge-user01.yaml`。  
仓库里的 [clash-verge-template.yaml](clash-verge-template.yaml) 只是模板，**一般不用自己填写**。

## 1. 导入个人配置

打开 Clash Verge Rev，在左侧进入「订阅」。

注意：页面上的「导入」按钮是用来填写**订阅网址**的，不要把本地 yaml 往那里贴。

导入本地文件，任选一种即可：

1. 在「订阅」页点击「新建」→ 选择「本地」→「选择文件」→ 选中 Kenny 发给你的 yaml →「保存」。
2. 或者直接把 yaml 文件拖进「订阅」页面。

导入后，在列表里**点一下**刚刚出现的配置，确认它处于选中状态。  
请新建一份配置，不要覆盖你原来的配置，也不要删除旧节点。

## 2. 必须打开虚拟网卡模式（TUN）

这一步是必做的，不是可选项。

「虚拟网卡模式」（TUN）会接管本机几乎所有程序的网络，包括浏览器、其他 App 和终端。只开「系统代理」时，很多软件（尤其是终端和部分桌面应用）仍会直连，看起来就像没生效。

请按顺序做：

1. 先安装系统服务，或在 Clash 内核旁点 ⚙️「授权」（见上一篇）。没有这一步，TUN 通常开不了。
2. 打开「虚拟网卡模式」。
3. 规则模式保持为「规则」。
4. 「系统代理」可以关掉，不是必需的。若你习惯开着，也可以开，但不替代 TUN。

**不要和 ClashX 或其他 VPN 同时开系统代理或虚拟网卡。** 用 Clash Verge 时，请先关掉其他代理软件的系统代理和增强模式。

## 3. 确认已经走通

1. 确认「虚拟网卡模式」已打开。
2. 打开 https://www.google.com ，应能打开。
3. 打开百度，应仍然正常（国内直连）。
4. 打开 https://ippure.com 查 IP，应显示国外出口，而不是你所在的国内城市。
5. 在终端执行（不要先设置 `http_proxy`）：

   ```bash
   curl -I --max-time 15 https://www.google.com
   ```

   应能返回 HTTP 头。这能证明终端也走了代理，说明 TUN 已生效。

如果 Google 打不开，或终端 `curl` 失败：回到「订阅」确认配置已选中；确认系统服务已安装且「虚拟网卡模式」已打开；确认没有其他代理软件在抢网络；检查系统时间是否自动同步。

## 4. 这套规则大致会怎么分流

- 国内网站、局域网：直连。
- 网易 UU 远程相关程序和域名：直连，避免和远程桌面抢路。
- 常见查 IP 网站（含 ippure、ip138 等）：走代理，避免查到真实城市。
- 其他国外访问：走公司节点。其中部分 AI 站点会在服务器上再走 WARP，你这边不用额外设置。
