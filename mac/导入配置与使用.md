# 导入配置并开始使用

请使用 Kenny 私下发给你的个人文件，例如 `clash-verge-user01.yaml`。  
仓库里的 [clash-verge-template.yaml](clash-verge-template.yaml) 只是模板，**一般不用自己填写**。

## 1. 导入个人配置

打开 Clash Verge Rev，在左侧进入「订阅」。

注意：页面上的「导入」按钮是用来填写**订阅网址**的，不要把本地 yaml 往那里贴。

导入本地文件，任选一种即可：

1. 在「订阅」页点击「新建」→ 选择「本地」→「选择文件」→ 选中 Kenny 发给你的 yaml →「保存」。
2. 或者直接把 yaml 文件拖进「订阅」页面。

导入后，在列表里**点一下**刚刚出现的配置，确认它处于选中状态。  
请新建一份配置，不要覆盖你原来的配置，也不要删除旧节点。

## 2. 打开虚拟网卡（推荐）

Kenny 这边使用的是「虚拟网卡模式」（TUN）。它能接管终端、部分不走系统代理的软件（例如一些命令行工具），更省事。

1. 确认已经安装好系统服务（见上一篇）。
2. 打开「虚拟网卡模式」。
3. 规则模式保持为「规则」。

也可以只开「系统代理」。这时浏览器一般可以，但终端和部分 App 可能仍是直连。推荐用虚拟网卡。

**不要两个一起乱开，更不要和 ClashX 或其他 VPN 同时开系统代理 / 虚拟网卡。** 用 Clash Verge 时，请先关掉其他代理软件的系统代理和增强模式。

## 3. 确认已经走通

1. 打开 https://www.google.com ，应能打开。
2. 打开百度，应仍然正常（国内直连）。
3. 打开 https://ippure.com 查 IP，应显示国外出口，而不是你所在的国内城市。
4. 若已打开虚拟网卡，在终端执行：

   ```bash
   curl -I --max-time 15 https://www.google.com
   ```

   应能返回 HTTP 头。不用再手动设置 `http_proxy`。

如果 Google 打不开：回到「订阅」确认配置已选中；确认虚拟网卡或系统代理已打开；确认没有其他代理软件在抢网络；检查系统时间是否自动同步。

## 4. 这套规则大致会怎么分流

- 国内网站、局域网：直连。
- 网易 UU 远程相关程序和域名：直连，避免和远程桌面抢路。
- 常见查 IP 网站（含 ippure、ip138 等）：走代理，避免查到真实城市。
- 其他国外访问：走公司节点。其中部分 AI 站点会在服务器上再走 WARP，你这边不用额外设置。
